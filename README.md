**Download the transcripts of YouTube videos and playlists as text, JSON, SRT or WebVTT files**

YouTube Transcript Downloader is a small command-line tool. You give it video URLs, playlist URLs, IDs or a file with
a list of URLs. It downloads the transcript of each video with
[youtube-transcript-api](https://github.com/jdepoix/youtube-transcript-api) and writes one file per video.

## Features

- 🔗 **Accepts URLs in any common form**: `youtube.com/watch?v=…`, `youtu.be/…`, `/shorts/…`, `/embed/…`, `/live/…`
  or the bare 11-character ID
- 📃 **Expands playlists** to all their videos, using [yt-dlp](https://github.com/yt-dlp/yt-dlp) (no video is
  downloaded)
- 📄 **Reads list files**: one URL per line; commas, blank lines and `#` comments are ignored
- 🌍 **Language preference** with fallback: if none of your languages exists, it takes the first available transcript
- 🧾 **Four output formats**: plain text, JSON, SRT and WebVTT
- 🔁 **Continues on errors** and prints a summary at the end

> [!NOTE]
> Written in May 2026 as a quick script to collect the transcripts of a list of videos. Turned into a command-line
> tool with uv and Ruff in November 2026.

## Quick start

Requirements: [uv](https://docs.astral.sh/uv/getting-started/installation/). uv installs the right Python version
itself.

1. Clone the repository:

   ```bash
   git clone git@github.com:HuberNicolas/youtube-transcript-downloader.git
   ```

   ```bash
   cd youtube-transcript-downloader
   ```

2. Install the dependencies:

   ```bash
   uv sync
   ```

3. Download a transcript:

   ```bash
   uv run yt-transcript https://www.youtube.com/watch?v=Tn-XvYG9x7w
   ```

   The file is written to `transcripts/Tn-XvYG9x7w.en.txt`.

To use the command anywhere without `uv run`, install it as a tool:

```bash
uv tool install .
```

## Usage

```text
yt-transcript [VIDEO ...] [-f FILE] [-o OUT] [-l LANGS] [--format {txt,json,srt,vtt}] [--delay SECONDS] [--strict]
```

| Argument | Default | Meaning |
|---|---|---|
| `VIDEO` | – | Video or playlist URLs or IDs |
| `-f`, `--file` | – | File with one URL or ID per line; can be given more than once |
| `-o`, `--out` | `transcripts` | Output folder |
| `-l`, `--lang` | `de,en` | Preferred languages in order, comma-separated |
| `--format` | `txt` | Output format: `txt`, `json`, `srt` or `vtt` |
| `--delay` | `1` | Seconds to wait between videos; raise it for large playlists if YouTube blocks you |
| `--strict` | off | Fail if none of the preferred languages exists, instead of taking another one |

Every URL with `list=` counts as a playlist, also a `watch?v=…&list=…` URL: the tool downloads the whole
playlist. To get only that one video, remove `&list=…` from the URL or pass the video ID.

Output files are named `<video ID>.<language>.<format>`, for example `Q2AOOLpfvnc.de.txt`.

Examples:

```bash
# All videos in a list, as subtitles, English first
uv run yt-transcript -f videos.txt -l en,de --format srt

# A whole playlist
uv run yt-transcript "https://www.youtube.com/playlist?list=PLzMcBGfZo4-mtY_SE3HuzQJzuj4VlUG0q"

# Two videos into a custom folder
uv run yt-transcript Tn-XvYG9x7w https://youtu.be/Q2AOOLpfvnc -o ~/Documents/transcripts
```

A list file looks like this:

```text
# Training videos
https://www.youtube.com/watch?v=Tn-XvYG9x7w
https://youtu.be/Q2AOOLpfvnc,
https://www.youtube.com/playlist?list=PLzMcBGfZo4-mtY_SE3HuzQJzuj4VlUG0q
```

The exit code is `1` if at least one video failed, so the tool can be used in scripts.

## Known issues

- Only videos with captions work, either uploaded by the creator or generated by YouTube. Videos without any
  captions fail with `TranscriptsDisabled` or `NoTranscriptFound`.
- YouTube blocks many cloud and VPN IP addresses, and also any address that sends many requests in a short time.
  If requests fail with `RequestBlocked` or `IpBlocked`, wait an hour, raise `--delay`, run the tool from a home
  connection or see the
  [proxy section](https://github.com/jdepoix/youtube-transcript-api#working-around-ip-bans-requestblocked-or-ipblocked-exception)
  of youtube-transcript-api.
- The tool uses an unofficial YouTube endpoint. A change at YouTube can break it until youtube-transcript-api is
  updated; then run `uv lock --upgrade`. The same applies to yt-dlp for playlists.
